# ARC9 for Homigrad

This addon adds **ARC9 Base support** for **Homigrad by JonnyBro**.

### Requirements:
- Homigrad by JonnyBro
- ARC9 Base

### Links:
- **Homigrad (JonnyBro):** [https://github.com/JonnyBro/homigrad]
- **ARC9 Base:** [https://github.com/necoarctic/ARC-9]
- **ARC9 for Homigrad** [https://steamcommunity.com/sharedfiles/filedetails/?id=3818459033]

### Important Information:
⚠️ **This is the first version of the addon.**

Many ARC9 weapons are currently buggy and may not work properly with Homigrad.

✅ **Modern Warfare 2019 (ARC9)** is currently the only weapon pack confirmed to work properly.

More fixes and improvements may be added in future updates.
